# **Word Raider**
a terminal-based word guessing game inspired by classic word puzzle games.
## Features
- Random word selection from a word bank
- ANSI color-coded hints
- Input validation
- Win statistics
- Previous guess history
- Incorrect letter tracker
- Correct duplicate-letter handling using a two-pass algorithm
